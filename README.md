# NORTH WEB — northwebstudio.nl

Одностраничный сайт веб-студии North Web. Чистый HTML + CSS + JavaScript:
**без фреймворков, без сборки, без npm**. Папку можно просто загрузить на любой хостинг.

---

## 1. Структура проекта

```
northweb/
├── index.html            ← весь сайт: тексты, цены, проекты
├── 404.html              ← страница «не найдено»
├── assets/
│   ├── css/style.css     ← дизайн: цвета, шрифты, отступы, анимации
│   ├── js/main.js        ← поведение + НАСТРОЙКИ (CONFIG) вверху файла
│   ├── fonts/            ← шрифты (хранятся локально, без Google Fonts)
│   └── images/
│       ├── og-image.jpg  ← картинка для превью в WhatsApp/LinkedIn/Facebook (1200×630)
│       └── work/         ← скриншоты проектов (.avif + .webp)
├── favicon.svg, favicon-32.png, apple-touch-icon.png, icon-192.png, icon-512.png
├── site.webmanifest
├── robots.txt            ← разрешает индексацию, указывает на sitemap
├── sitemap.xml           ← карта сайта для Google
├── .htaccess             ← HTTPS-редирект, кэш, сжатие (только для Apache-хостинга)
└── README.md             ← этот файл (на хостинг загружать не обязательно)
```

> `.htaccess` — скрытый файл (начинается с точки). В Finder: `Cmd + Shift + .`, в Windows: «Вид → Скрытые элементы».

## 2. Запустить сайт локально

Сайт можно открыть двойным кликом по `index.html`, но правильнее через маленький локальный сервер (тогда всё работает как на хостинге):

**Вариант A — Python (есть на Mac/Linux):**
```bash
cd путь/к/northweb
python3 -m http.server 8000
```
Откройте http://localhost:8000

**Вариант B — VS Code:** установите расширение **Live Server**, правый клик по `index.html` → *Open with Live Server*. Страница обновляется сама при сохранении.

## 3. Где что менять

### Тексты
Все тексты — в `index.html`. Файл разбит на блоки с заголовками-комментариями:
`HEADER`, `HERO`, `WERK / SHOWCASE`, `DIENSTEN`, `WAAROM NORTH WEB`, `WERKWIJZE`, `PRIJZEN`, `OVER`, `FINAL CTA`, `CONTACT`, `FOOTER`.
Найдите нужный текст (Ctrl/Cmd + F) и замените. Структуру тегов не трогайте — только текст между ними.

Заголовки разбиты на строки так:
```html
<span class="line"><span>Een website</span></span>
```
Каждая такая строка анимируется отдельно. Чтобы изменить заголовок — меняйте текст внутри, сохраняя обёртки.

### Цены
В `index.html` ищите `PRIJS`:
```html
<!-- PRIJS: Website -->
<p class="price-amount"><span class="price-from">vanaf</span> €750</p>
```
Меняете только число. Совет: для бизнес-клиентов в NL принято указывать цены **excl. btw** — если так, допишите это в текст под ценами (`Elke website is anders…`).

### Контактные данные (e-mail)
Сейчас стоит **infonorthwebstudio.nl@gmail.com**. Чтобы заменить, поменяйте адрес в трёх местах:
1. `assets/js/main.js` → `CONFIG.email`
2. `assets/js/main.js` → `CONFIG.formEndpoint` (адрес в конце ссылки FormSubmit)
3. `index.html` → поиск по старому адресу (блок Contact и footer)

### Цвета и шрифты
`assets/css/style.css`, раздел **2. Design tokens** в начале файла:
```css
--ivory: #F4F0E8;   /* фон */
--ink: #141312;     /* текст */
--accent: #D2502A;  /* единственный акцентный цвет */
```

### SEO
В `<head>` файла `index.html`: `<title>`, `meta description`, `canonical`, Open Graph и structured data (JSON-LD). Основной адрес сайта — `https://www.northwebstudio.nl/` (без www идёт переадресация, так настроено в Vercel). Если домен изменится — замените его везде в `index.html`, `robots.txt`, `sitemap.xml` и `.htaccess`.

## 4. Изображения

- Все картинки проектов — в `assets/images/work/`.
- Формат: **AVIF** (основной, самый лёгкий) + **WebP** (запасной). Браузер сам выбирает.
- Ширина для десктоп-скриншота ~2000–2400 px, для мобильного ~780 px.
- Конвертировать бесплатно: https://squoosh.app (выбрать AVIF, качество ~60; затем WebP, качество ~80).
- В HTML у каждой картинки указаны `width` и `height` — это предотвращает «прыжки» страницы. При замене картинки обновите эти числа.
- Всё, что ниже первого экрана, грузится с `loading="lazy"`.

## 5. Добавить новый проект в «Selected work»

1. Положите скриншоты в `assets/images/work/` (например `bakkerij-desktop.avif/.webp` и `bakkerij-mobile.avif/.webp`).
2. В `index.html` скопируйте целиком блок `<article class="project" data-project> … </article>` (PROJECT 01) и вставьте под ним.
3. Замените: пути к картинкам, `alt`-тексты, номер (`02`), название, город, категорию.
4. Если это реальный клиент — удалите строку `<li class="tag-concept">Concept project</li>`.
5. Для всплывающего окна с деталями: скопируйте блок `<dialog … id="project-humphrey">` внизу страницы, дайте новый `id` (например `project-bakkerij`) и укажите этот же `id` в `data-open-dialog="project-bakkerij"` и `href="#project-bakkerij"` у нового проекта.
Проект может вести не на всплывающее окно, а на живую демо-версию (как Atelier Hair, PROJECT 02): у ссылки `project-stage` вместо `data-open-dialog` стоят `href="https://…"`, `target="_blank"` и `data-cursor-label="Live demo ↗"`.

6. Блок «Hier komt jouw bedrijf.» (`project-next`) можно оставить последним или удалить, когда проектов станет много.

⚠️ Humphrey Hair Design — **концепт**, не клиент. Это явно указано на сайте («Concept project» и пояснение в окне проекта). Не убирайте эти пометки, пока салон не станет настоящим клиентом.

## 6. Контактная форма

Форма подключена к бесплатному сервису **FormSubmit** (formsubmit.co): заявки приходят письмом на `CONFIG.email`. При самой первой отправке FormSubmit присылает письмо «Activate Form» — нужно один раз нажать ссылку в нём, иначе заявки не доставляются. Пока форма не активирована или сервис недоступен, посетитель видит честное сообщение об ошибке и ссылку «отправить по e-mail» — фальшивого «успешно отправлено» нет.

Если `formEndpoint` оставить пустым, форма ничего не отправляет и сразу предлагает посетителю написать по e-mail.

Альтернативы FormSubmit (тоже без своего сервера) — меняется `CONFIG.formEndpoint` в `assets/js/main.js`:

**Formspree** (https://formspree.io)
1. Зарегистрируйтесь, создайте форму, получите адрес вида `https://formspree.io/f/abcdwxyz`.
2. `formEndpoint: 'https://formspree.io/f/abcdwxyz'`

**Web3Forms** (https://web3forms.com)
1. Получите access key на свой e-mail.
2. `formEndpoint: 'https://api.web3forms.com/submit'`
3. `formExtraFields: { access_key: 'ваш-ключ' }`

**Свой PHP-скрипт** (если хостинг поддерживает PHP): `formEndpoint: '/contact.php'` — скрипт должен принимать POST с полями `naam`, `bedrijf`, `email`, `telefoon`, `bericht` и возвращать код 200.

После подключения отправьте тестовое сообщение и проверьте, что письмо пришло.
Про AVG/GDPR: страница `privacy.html` (privacyverklaring) уже есть, ссылка на неё стоит под формой и в футере. Если начнёте пользоваться другими сервисами (аналитика, другой провайдер формы или почты) — обновите раздел 4 и дату вверху страницы. Имя владельца и KvK-номер вписываются в раздел 1 (комментарий `BEDRIJFSGEGEVENS`).

## 8. Публикация

### Что загружать на хостинг
**Всё содержимое папки `northweb/`** (не саму папку, а то, что внутри) — в корневую папку сайта на хостинге. Обычно она называется `public_html`, `www`, `htdocs` или `domains/northwebstudio.nl/public_html`. `README.md` загружать не обязательно.

После загрузки в корне сайта должны лежать `index.html`, папка `assets`, `favicon.svg` и т.д.

### Вариант A — обычный хостинг (TransIP, Vimexx, Hostnet, Antagonist, mijn.host и т.п.)
1. Купите хостинг-пакет и, если ещё нет, домен `northwebstudio.nl` (часто у того же провайдера).
2. Загрузите файлы через **файловый менеджер** в панели управления или через **FTP/SFTP** (программа FileZilla: хост, логин и пароль даёт хостинг).
3. Если домен куплен у того же провайдера — DNS обычно настроен автоматически.
4. Включите **SSL (Let's Encrypt)** в панели хостинга — как правило, одна кнопка, бесплатно.
5. Когда сайт открывается по `https://` — файл `.htaccess` автоматически перенаправит всех с `http://` и `www.` на `https://northwebstudio.nl`.

### Вариант B — бесплатно: Netlify / Cloudflare Pages / Vercel
1. Зарегистрируйтесь, выберите «Deploy manually» и перетащите папку `northweb` в окно браузера.
2. В настройках проекта: **Domains → Add custom domain → northwebstudio.nl**.
3. Сервис покажет, какие DNS-записи добавить (см. ниже). SSL включается сам.
4. `.htaccess` там игнорируется — это нормально, HTTPS-редирект сервисы делают сами.

### DNS — как привязать домен
DNS настраивается там, где куплен домен (раздел «DNS» / «DNS-beheer»). Обычно нужны две записи:

| Тип   | Имя (host) | Значение                                   |
|-------|-----------|---------------------------------------------|
| A     | `@`       | IP-адрес сервера (даёт хостинг)             |
| CNAME | `www`     | `northwebstudio.nl` (или адрес от хостинга) |

Для Netlify/Vercel значения другие — они показывают их в настройках домена.
Изменения DNS вступают в силу от нескольких минут до 24 часов. Проверить: https://dnschecker.org

Почта (`info@…`) настраивается отдельными **MX-записями** — их даёт почтовый провайдер. Не удаляйте существующие MX-записи, меняя A/CNAME.

### HTTPS / SSL
- На обычном хостинге: панель → SSL → Let's Encrypt → включить для `northwebstudio.nl` и `www.northwebstudio.nl`.
- Проверка: в адресной строке замок, адрес начинается с `https://`.
- Если после включения `.htaccess` сайт «зацикливается» (too many redirects) — у хостинга свой редирект; закомментируйте блок 1 в `.htaccess` (поставьте `#` в начале строк).

### После запуска
1. Зарегистрируйте сайт в **Google Search Console** (https://search.google.com/search-console), подтвердите домен и отправьте `https://northwebstudio.nl/sitemap.xml`.
2. Проверьте превью ссылки: https://www.opengraph.xyz
3. Проверьте скорость: https://pagespeed.web.dev

## 9. Обновление сайта после публикации

1. Меняете файлы локально, проверяете через локальный сервер (раздел 2).
2. Загружаете **только изменённые файлы** на хостинг поверх старых (FTP/файловый менеджер) или перетаскиваете папку заново в Netlify.
3. Если изменения не видны — обновите страницу с очисткой кэша: `Ctrl + Shift + R` (Windows) / `Cmd + Shift + R` (Mac).
4. Если изменили CSS/JS, а у посетителей старая версия — добавьте версию к ссылке в `index.html`: `style.css?v=2`, `main.js?v=2`.
5. Обновите дату `<lastmod>` в `sitemap.xml`, если изменения существенные.

## 10. Backup

- **Главная копия — это ваша локальная папка.** Храните её в облаке (iCloud / Google Drive / Dropbox) — это уже бэкап.
- Ещё лучше — **Git + GitHub** (приватный репозиторий): каждое изменение сохраняется, можно откатиться к любой версии.
  ```bash
  git init
  git add .
  git commit -m "Eerste versie"
  ```
- Перед большими изменениями делайте zip-архив с датой: `northweb-2026-10-05.zip`.
- У хостинга обычно есть автоматические бэкапы — проверьте в панели, как часто и сколько дней хранятся.

## 11. Перенос сайта на другой хостинг

1. Скачайте все файлы (или возьмите свою локальную копию).
2. Загрузите их на новый хостинг (раздел 8).
3. Включите SSL на новом хостинге.
4. Поменяйте A/CNAME-записи DNS на новые значения. MX (почту) не трогайте, если почта остаётся у старого провайдера.
5. Подождите обновления DNS, проверьте сайт, только потом отключайте старый хостинг.

Базы данных нет — поэтому перенос сводится к копированию файлов.

## 12. Использовать как основу для сайтов клиентов

Проект специально сделан переносимым:
1. Скопируйте папку, переименуйте (например `bakkerij-jansen/`).
2. Замените тексты в `index.html`, цвета и шрифты в `style.css` (раздел Design tokens).
3. Замените домен везде: `index.html` (canonical, og:url, og:image, JSON-LD), `robots.txt`, `sitemap.xml`, `.htaccess`.
4. Замените фавиконки, `og-image.jpg`, `site.webmanifest`.
5. Поменяйте `CONFIG` в `main.js` (почта клиента, форма).
6. **Передача клиенту:** домен и хостинг лучше регистрировать на имя клиента (или чётко прописать в договоре, кому они принадлежат). Передайте: доступ к хостингу, доступ к регистратору домена, zip-архив сайта и этот README.

Для клиента с JSON-LD: у локального бизнеса (салон, гараж) уместен тип `LocalBusiness` / `HairSalon` / `AutoRepair` с адресом и часами работы — но только с **настоящими** данными клиента.

## 13. Технические заметки

- **Анимации:** без библиотек. Появление блоков — IntersectionObserver + CSS-переходы. Интерактивное «поле компаса» в hero — `<canvas>`, ставится на паузу вне экрана.
- **prefers-reduced-motion:** если в системе включено «Уменьшить движение», все анимации отключаются, поле в hero статично.
- **Мобильные:** параллакс и «магнитная» кнопка отключены, курсор-метка скрыта; поле в hero движется само, медленно.
- **Без JavaScript** весь контент виден (анимации просто не включаются).
- **Шрифты:** Inter, Inter Display и Lora Italic — все по лицензии SIL Open Font License, хранятся локально (никаких запросов к Google — плюс для AVG/GDPR). Формат WOFF; при желании можно сконвертировать в WOFF2 (например, на https://cloudconvert.com) и поменять `format("woff")` → `format("woff2")` в `style.css`.
- Проверено на ширинах 375 / 390 / 430 / 768 / 1440 px — без горизонтальной прокрутки.
